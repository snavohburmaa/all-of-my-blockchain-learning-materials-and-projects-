# ERC-20 Token Project

A simple ERC-20 token implementation built with Foundry and OpenZeppelin.

## Token Information

- **Name**: OhBurmaa
- **Symbol**: OB
- **Initial Supply**: 1,000,000 tokens

## Features

- Standard ERC-20 token functionality
- All tokens minted to deployer upon creation
- Non-mintable after deployment (fixed supply)

## Project Structure

- `src/OurToken.sol` - Main token contract
- `script/DeployOurToken.s.sol` - Deployment script
- `test/OurTokenTest.t.sol` - Test suite
